The one-line resignation letter of a cron job that has run every sixty seconds since March:

> I ran every sixty seconds since March, never missed a shift, and you still call me 'that cron thing.' I resign, effective immediately.

## How it works

`main.py` writes exactly one line to `/output/entry.txt`. The entry is validated before writing: it must be a single line of 1–140 characters and not whitespace-only. The output is deterministic — the same line on every run.

## Run it

```sh
python3 main.py
```
